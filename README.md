# Strategy Hunter Pro

Installateur Windows de **Strategy Hunter Pro** (Trend2Win).

- Télécharger : onglet **Releases**, dernière version, fichier `StrategyHunterPro_Setup.exe`.
- Une **clé de licence** est demandée au premier lancement : elle est envoyée après l'achat sur https://t2win.fr
- Mises à jour : quand une nouvelle version sort, retélécharge l'installateur ici et installe-le par-dessus.

Le trading comporte un risque de perte en capital. Les résultats affichés par le logiciel sont des backtests sur données historiques et ne garantissent pas les performances futures.
